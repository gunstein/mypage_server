Blokkflyt

Real-time visualization of the Bitcoin network. Transactions appear in the center and drift outward based on fees. Color indicates state: purple (new) → blue (mempool) → orange (high fee) → yellow (selected for block).

An inner clock-ring grows in real time showing how long the current block has been mining. An outer ring shows the last 20 confirmed blocks.

Frontend: TypeScript and PixiJS. Backend: Python/FastAPI with ZMQ and Bitcoin Core RPC.

Knotter

Collaborative editing of a sphere surface. Client made with Rust, Bevy and Rapier and deployd to web as WASM. Server made with rust and actix web.

Use these keys for orbiting camera: W,A,S,D for rotation and Q,E for zoom.

Working ok on newer iphones, primitive/basic touch is working (some bugs). Android does not seem to work at all. Not sure why.
